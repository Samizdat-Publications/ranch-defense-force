# Progress — the visual record

Every screenshot this project has kept, newest first. Written by
`npm run snap`; **this file is GENERATED** — rebuild it with
`npm run snap -- --index` rather than editing it, because the directory is
the source of truth and a hand-edited index drifts from it.

Nothing was kept before 2026-08-29. `npm run shot` wrote to a gitignored
path that the next shot overwrote, so sixteen sessions left no record at
all. The dated entries earlier than that were RECONSTRUCTED by building old
commits in a throwaway git worktree and re-shooting them — see
`tools/snap-history.ts`. They are what those commits look like when built
today, which is as close to a contemporary screenshot as anything can now
get, and the commit each one names is the real one.
