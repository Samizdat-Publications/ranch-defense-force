RANCH DEFENSE FORCE — DESIGN PASS 2 OF 4

Home screen

Not a title and a list — a place you are standing in. Two places, in fact: the scene alternates every load, so the game does not open the same way twice. Every object is real 32px LimeZu art at 2× integer zoom, composited in DOM and animated in CSS only. The UI layer never changes between scenes; only the Homestead call-out moves, because the barn is in a different spot.

THE ROTATION
On boot, read the last scene from local storage and mount the other one. Two files today — Yard Scene and Field Scene — and adding a third is one more entry in the list, no change to menu.ts. The button top-right is a reviewer control, not shipped.
SPRITE MOTION
One strip PNG per actor plus background-position in pixels with steps(n). Left-facing and right-facing walks are separate strips — never a mirrored sprite, so nothing ever walks backwards. Travel is a second animation on the parent, so cadence and speed tune independently.
SCALE AND THE UI SAFE BAND
Scale carries the depth, and every step is integer: distant buildings at 1×, actors at 2×, and a foreground building at 2× cropped by the frame edge — the yard silo is the one that sells it. Everything that moves lives in the band the UI leaves clear: y 600–726 across the middle, plus the bottom-left corner below the seed box. The right margin is the silo's now, so nothing animates there.
DEPTH IN THE FIELD SCENE
Four crop rows, each one taller, slower and blurrier than the row behind it — the front row carries a 3px blur, the second 1.2px, and the skyline buildings 0.6px. That is the whole depth trick, and it is what lets a flat DOM stack read as a field going away from you. The tractor works the middle distance on a 46-second pass with two offset exhaust puffs.
LOCKED CLASSES
A locked class is not a black silhouette with a price. It is a packet somebody nailed shut: two boards across the window, the figure still visible in the gap, and the acre price branded on the top board. You can see there is somebody in there.
ONE THING TO FLAG
Four of the six classes reuse the two shipped farmer sheets here, because their generated sheets do not exist in the repo yet — npm run characters builds them from art/characters.json. The Portrait Generator does ship at 32×32 (assets/modern-ui/32x32/Portrait_Generator_32x32/, 85 accessories alone), so bust portraits are available for these cards whenever you want them — I corrected an earlier note that said otherwise.
