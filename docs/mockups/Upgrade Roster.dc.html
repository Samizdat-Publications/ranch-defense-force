The Upgrade Roster

Fifty-six upgrades: 40 items and 16 weapons, every one tiered, priced and assigned to a pool. The complaint was "the same five things over and over" — the fix is not only more cards but a shop that holds cards you cannot draw any other way. Every epic and legendary is shop-only, so the shop is where a run gets its shape.

Both files are drop-in: content/items.json replaces src/content/items.json outright, and content/weapons-additions.json merges into src/content/weapons.json. Shapes match what is already there.

The level-up draw

Plain numbers, named after the object. A common is one stat and nothing else to read — the point of a common is that you take it in a second and get back to the field.

POOL 02

Shop only

{{ shopCount }} cards · four offered after waves 5, 10, 15, 20 and 24

These are the run-definers. Five shop visits, four cards a visit, so a player sees at most twenty of these in a full run and can afford far fewer — which is what makes two runs differ. Nothing here is a percentage; every one of them changes a rule.

POOL 03

Sixteen weapons

twelve retuned into tiers, four new

Weapons draw on the same tier weights as items, so a Legendary weapon is exactly as rare as a Legendary item. The four new ones reuse behaviours that already ship — the auger and the combine head are both arcSwing retuned, the bell is slam with the stun taken out — so none of them needs new engine work to be playable.

HANDOFF

What this needs from code

WORKS TODAY
Twenty-eight of the forty items are stat mods, tool upgrades, elements or specials the code already dispatches — drop the file in and they work. Thirty once the two new mod keys are added. Same for all sixteen weapons: the new four use shipped behaviours.
NEW MOD KEYS
minionPct and dodgePct are the only stat keys that do not exist yet — dodge is already on The Kid's class stats, so it is a lookup, not a system. Everything else reuses existing keys.
NEW SPECIALS
Ten need a new branch in the special dispatch: chainOnKill, trailGas, touchStun, gasImmune, stunMultiplier, scytheSecondBlade, pierceAllAndReswing, saltRing, bullMinion, firstHitShield. They are ordered here roughly cheapest first; the epics are all one-line hooks into existing systems, the legendaries are the real work.
NEW FIELDS
maxStacks caps copies per run (5/4/3/2/1 by tier) so a run cannot become nine Whetstones. _mockArt is a design-review path only — strip it on import. cardSprite: every value the atlas cannot resolve today carries an _atlas marker in the JSON. 18 are NEW ATLAS KEY — an itemIcons entry plus art for most of them (SPRITE_REQUESTS.md lists which). 7 are FRAME PICK — the clip is already packed and only needs a named frame exported as an icon, which is the cheap group.
BALANCE, HONESTLY
The numbers are authored from the existing file's scale, not from play. Run them through the balance harness before you trust the epics — Threshing Floor and Crop Duster are the two most likely to be quietly broken with the right weapon.
ART
Every card draws real owned art at integer zoom — 32px icons at 4×, guns at 6×, the dog at 2×, the tractor at 1×. Five families are pulled from places sprites.json does not reach yet: the gas mask and the two hats cropped from character-generator accessory sheets, the gas cloud from one frame of fx.gas, the three rounds from their own projectile sheets, and the Bull from the Cow_Big_Black walk band, darkened.
