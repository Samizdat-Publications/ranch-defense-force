# Ranch Defense Force

A Vampire Survivors–style survivor-shooter set on a farm/ranch, built from LimeZu
pixel-art asset packs.

> **Private repo.** The art in `assets/` is commercially licensed but **may not be
> redistributed**. Do not make this repository public and do not publish the raw
> asset files. See [ASSETS.md](ASSETS.md).

## Status

Pre-design. Assets are staged; game design and implementation not started.

## Layout

```
assets/
  modern-farm/    LimeZu "Modern Farm" v1.2  — tiles, animals, crops, buildings, characters
  modern-ui/      LimeZu "Modern User Interface" — HUD, buttons, panels, portrait pieces
```

Both packs ship art at three resolutions: `16x16/`, `32x32/`, `48x48/`. Pick one
scale and stay on it — mixing scales in one scene is the fastest way to make
pixel art look wrong.

See [ASSETS.md](ASSETS.md) for a directory-level map of what's in each pack.
