# Generated sprites

Output from the two LimeZu generator apps (Farmer Generator, Portrait Generator).
Save exports here rather than leaving them in `~/Downloads` or the app folder.

Suggested naming so the design agent can tell things apart:

```
hero_farmer.png           the main player character sheet
enemy_farmhand_01.png     variant characters
portrait_hero.png         portrait art
```

Note which scale you exported at (16/32/48) — either in the filename or here —
since the sheets look similar but won't line up if mixed.
